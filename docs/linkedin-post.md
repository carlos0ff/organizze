# Post LinkedIn — Organizze + Desafio Backend WorkFacilit

---

🚀 **Construindo um sistema financeiro do zero — com IA como copiloto**

Nos últimos meses venho desenvolvendo o **Organizze**, um sistema de gestão financeira pessoal completo:

- Dashboard com métricas financeiras
- Controle de lançamentos, cartões, limites por categoria
- Integração com Open Finance
- Blog, landing page e autenticação com rate limiting

Stack: **Laravel 12 · Vue 3 · Inertia.js · Tailwind CSS · TypeScript · Docker**

---

**O que muda quando você usa IA no desenvolvimento?**

Usei o **Claude (Anthropic)** ao longo de todo o processo — reorganizei 60+ controllers em uma arquitetura por domínio, implementei auth funcional, construí a landing page completa e resolvi bugs em minutos que antes me tomavam horas.

Mas o ponto mais importante: em nenhum momento simplesmente copiei código sem entender. A IA funciona como um par de programação disponível 24h — você ainda precisa saber o que está construindo e por quê.

---

**O experimento mais interessante:**

Pedi ao Claude para criar um **desafio técnico real para devs PHP/Laravel júnior** — o tipo que uma empresa usaria num processo seletivo.

O resultado? O **desafio-backend-workfacilit**: uma API REST completa de workflows de aprovação dinâmica (etapas, condicionais, aprovação múltipla, auditoria, Redis, testes com Pest).

O nível de detalhe foi impressionante — critérios de avaliação claros, requisitos técnicos e funcionais separados, e casos de borda bem especificados.

👉 https://github.com/carlos0ff/desafio-backend-workfacilit
