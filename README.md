## 🎯 Sobre o Projeto

Este projeto é um clone funcional e moderno do popular aplicativo de controle financeiro pessoal e empresarial, [Organizze](https://www.organizze.com.br/). O objetivo é recriar as principais funcionalidades de gestão financeira, como controle de despesas, receitas, contas e cartões, utilizando uma stack tecnológica robusta e atualizada.

O foco principal é oferecer uma interface de usuário intuitiva e responsiva, replicando a experiência de "dinheiro sob controle, sem esforço" que o Organizze original proporciona.
